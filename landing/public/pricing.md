# EzzySync Pricing

## 1. Starter Tier
**Price:** ₹0 (Free forever)
**Best for:** New independent agents just starting out.
**Features:**
- Up to 15 Active Leads
- Basic Kanban Board
- 1 User Account
- Manual Follow-ups
- WhatsApp Click-to-Chat

## 2. Agency Growth Tier
**Price:** ₹2,499 / month (billed annually at ₹29,988/yr) or ₹2,999 / month (billed monthly)
**Best for:** Growing travel agencies seeking automation and efficiency.
**Features:**
- Unlimited Active Leads
- Advanced Kanban Board
- Unlimited User Accounts
- WhatsApp Cloud API Integration (Automated alerts)
- PDF Invoicing & Receipts
- Profitability Tracking & Ledger
- AI Itinerary Builder (Beta)
- Priority Email Support

## 3. Enterprise Tier
**Price:** Custom Pricing
**Best for:** Large DMCs and B2B aggregators needing tailored solutions.
**Features:**
- Custom API Integrations (Flight/Hotel suppliers)
- Dedicated Account Manager
- Custom Onboarding & Data Migration
- White-labeled Client Portal
- 24/7 Phone Support
